# CRITICAL HIT!

Pokémon-style midterm review battle for WCTA Cyber. Static site: `index.html` + `banks/*.csv`. No build step.

Edit questions by uploading CSVs to `banks/` (see the teacher guide). Student progress is saved in each browser's localStorage only.

Creature data and sprites load at runtime from PokeAPI (https://pokeapi.co). Pokémon and Pokémon character names are trademarks of Nintendo. This is a non-commercial classroom project. Original creatures are drawn in code.
